# Evolución de la temperatura terrestre (1750-2015)

Proyecto de la asignatura Análisis estadístico avanzado (Universidad Carlos III de Madrid), Fase I.

## Contenido
- `Estadistica_Final__Luna_Garcia.R`: script de R con la importación, la calidad de los datos y los análisis univariante y bivariante.
- `GlobalTemperatures.csv`: datos de entrada.
- `figuras/` y `tablas/`: resultados generados por el script.

## Datos
Serie global mensual de temperaturas terrestres de Berkeley Earth, publicada en Kaggle:
https://www.kaggle.com/datasets/berkeleyearth/climate-change-earth-surface-temperature-data

## Cómo ejecutarlo
1. Instalar los paquetes: `readr`, `dplyr` y `DescTools`.
2. Ajustar la ruta de `setwd()` al principio del script a tu carpeta.
3. Ejecutar el script completo en RStudio.
